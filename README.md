# Flask Grinberg Practice

Personal repo for working through "Flask Web Development" by Miguel Grinberg.

## Setup

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Running

```bash
flask run
```
